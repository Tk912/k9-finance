# K9 פיננסים — ניהול הוצאות והכנסות של הבית

אפליקציית ווב בקובץ HTML יחיד (RTL, עברית) למעקב אחרי ההוצאות, ההכנסות, החסכונות והמשכנתא של הבית, על בסיס גיליון Google Sheets.

> ⚠️ **הריפו הזה פרטי ויישאר פרטי.** `index.html` מכיל נתונים פיננסיים אמיתיים של המשפחה. אין להפוך אותו לציבורי.

## קבצים

| קובץ | תיאור |
|---|---|
| `index.html` | האפליקציה המלאה: קוד, עיצוב, Chart.js מוטמע ונתונים מוטמעים |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | אייקונים (favicon / מסך הבית בנייד) |

## לשוניות

- **לוח בקרה**: מדדים מרכזיים עם שינוי חודש-מול-חודש, פילוח לפי קטגוריות, גרפים, סינון לפי שנה/חודש
- **תנועות**: הכל / הוצאות קבועות / הוצאות משתנות / הכנסות
- **חסכונות**
- **משכנתא**
- **הוספת רשומה**: רשימת רשומות ממתינות להעתקה לגיליון

## שימוש

פותחים את `index.html` בדפדפן. אין צורך בשרת או בהתקנה.

## מקור הנתונים

הגיליון החי ב-Google Sheets הוא מקור האמת. הנתונים מוטמעים בקובץ בזמן הסנכרון. סנכרון אוטומטי מהקובץ המקומי נחסם על ידי מדיניות CORS של Google, ולכן עדכון הנתונים נעשה על ידי סנכרון ידני ויצירה מחדש של הקובץ.
